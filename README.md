# Made with HyperFrames

Independent community video showcase. React frontend with a Node 24+ API and SQLite storage.

## Run

```sh
npm install
npm start
```

Run `npm run dev` to watch and rebuild the React client while the server runs. The source is in `src/app.jsx`; `public/app.js` is generated by `npm run build`.

Open http://localhost:3000. Includes a credited launch film from the [official HyperFrames examples](https://github.com/heygen-com/hyperframes/blob/main/docs/examples.mdx), search/category filters, shareable detail pages, and a submission form. The film and poster are served from HeyGen's media host. Submissions are stored in SQLite and are private until approved. No automated emails are sent.

## Review submissions

Run from this directory:

```sh
npm run submissions
node moderate.mjs approve SUBMISSION_ID
node moderate.mjs reject SUBMISSION_ID
```

Review video contents, rights, URLs, and descriptions before approval. Rejected entries remain in the private database. Contact emails are never returned by the public API. External URLs are not fetched by the server.

## Hosting

### Vercel preview

`npm run build:preview` exports the gallery and approved public fields into `dist`. `vercel.json` configures static hosting and showcase routes. The preview clearly disables submissions; it does not attempt to persist SQLite in a Vercel function. The local Node app retains submissions. `.vercelignore` excludes private local databases and credentials from uploads. A fresh deployment includes the curated official example; additional approved entries require an explicit content publishing pipeline before production.

Deploy a preview with `npx vercel deploy` from this folder after signing in to Vercel. No custom domain is needed to review the generated URL. Connect a hosted database before enabling submissions on Vercel.

### Full Node deployment

Deploy to a Node 24 host with persistent disk, not a static-only host. Set `HOST=0.0.0.0`, `PORT` as required by the host, and `DATA_DIR` to a persistent directory. Keep one server instance using this database. Back up the SQLite database, including its WAL state (use SQLite's backup facilities or stop the server before copying). Put HTTPS in front of the app and connect madewithhyperframes.com through the chosen host. The local default binds only to localhost.

The featured MP4 streams from HeyGen's media host. Submission rate limiting is process-local and uses the socket IP; behind a proxy, visitors share its limit. Configure proxy-aware or edge rate limits for public deployment. No accounts, direct file uploads, payments, or email delivery are implemented. Public deployment/DNS changes have not been performed.
